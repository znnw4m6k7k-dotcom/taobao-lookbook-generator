# 淘宝 Lookbook 生图 Agent 中文说明书

## 它能做什么

根据用户提供的成年模特、商品正反面与细节、完整穿搭参考，生成淘宝服饰 Lookbook。支持三种模式：

### 1. 标准模式（默认）
- 16张竖版图片：12张高调极简棚拍 + 4张干净城市街拍
- 3次重试机会
- 适合大多数商品

### 2. 高级模式
- 16-20张图片（可配置棚拍/街拍比例）
- 5次重试机会
- 适合主推款、复杂款式、营销活动

### 3. 自定义场景模式
- 先生成16张标准白背景棚拍图作为基础
- 再根据用户提供的场景背景图生成对应版本
- 支持多个场景（如：品牌咖啡厅、城市广场、花园等）
- 保持模特、服装、姿势完全一致，只更换背景和光照

每张图独立生成并交给 `$taobao-lookbook-reviewer` 审核，只有 A 级图片进入最终目录。

## 使用前准备

- 一位已获得 AI 生成和商业使用授权的成年模特：清晰人脸和全身比例参考。
- 一个 SKU、一个颜色；不同颜色必须分开任务。
- 商品正面、背面和关键细节图。
- 完整穿搭正面、背面参考，包括需要保留的鞋与配饰。
- 指明商品类型：连衣裙、上装、下装、套装或外套。

如果关键视图缺失、模糊、被遮挡或互相矛盾，Agent 会停止并要求补图，不会猜测商品结构。

## 在 Codex 中怎么说

上传或给出素材文件夹后发送：

### 标准模式（默认）
```text
使用 $taobao-lookbook-generator，根据这个素材文件夹生成16张3:4淘宝 Lookbook。先检查模特授权、商品正反面、细节和完整穿搭是否齐全；逐张生成,并用 $taobao-lookbook-reviewer 审核。
```

### 高级模式
```text
使用 $taobao-lookbook-generator 高级模式，生成20张 Lookbook（16棚拍+4街拍），最多5次重试。这是主推款，需要最高质量。
```

### 自定义场景模式
```text
使用 $taobao-lookbook-generator 自定义场景模式：
1. 先生成16张标准棚拍图
2. 然后使用我提供的场景背景图（scenes/cafe_bg.jpg 和 scenes/plaza_bg.jpg），每个场景生成8张
3. 保持模特、服装、姿势一致，只替换背景
```

**场景背景图要求**：
- 分辨率：至少2000px宽，建议2400px+
- 格式：JPG或PNG
- 内容：有清晰的前景空白位置，适合放置全身模特
- 光照：有明确的光源方向（窗光、自然光、顶光等）
- 禁止：背景中不能有人物，避免过于杂乱的背景

## 固定输出

### 标准/高级模式
- 16张（或配置数量）独立 JPG，1536 × 2048，3:4
- 12张纯白至浅冷灰高调极简棚拍
- 4张干净现代城市街拍
- 同一模特、同一商品、同一颜色和同一完整搭配
- 无文字、水印、拼图、第三方 Logo 或虚构品牌

### 自定义场景模式
- 基础套装：16张标准白背景棚拍图 → `final/studio/`
- 场景套装：每个场景N张（可配置） → `final/{场景名称}/`
- 所有图片：1536 × 2048，最高质量 JPG
- 模特、服装、姿势、搭配在所有版本中保持一致
- 只有背景和光照环境不同

**目录结构示例**（自定义场景模式）：
```
job_folder/
├── final/
│   ├── studio/              # 16张基础棚拍图
│   ├── cafe_interior/       # 8张咖啡厅场景
│   └── city_plaza/          # 8张城市广场场景
├── human-review/            # 未通过审核的图片
├── job-manifest.json        # 完整记录
└── cost-log.json           # 成本统计
```

12个人物镜头会从内置的12张动作卡中抽卡式生成，按正面、侧面、背面、行走和三分之四机位匹配，并在同组内尽量不重复；4张商品细节图不参与动作抽卡。没有真实口袋、肩带或配饰时，不会为了完成动作而凭空添加。

棚拍默认使用左前方30–45度超柔和大面积光源、70–85mm中长焦透视、f/5.6–f/8、略亮但高光不溢出的曝光、低对比中性色调、自然皮肤与织物纹理。

## 审核与返工

- A：可以进入 `final/`。
- B/C：根据审图 Agent 的具体意见只返工当前镜头。
- 标准模式：每张最多自动返工2次（共3次尝试）
- 高级模式：每张最多自动返工4次（共5次尝试）
- 自定义场景模式：基础棚拍图最多返工2次，场景版本最多返工2次
- 达到最大返工次数后仍不合格，进入 `human-review/`，不能冒充完成。

## 成本估算

生成前会显示预估成本（按每张生成约$1计算）：

- **标准模式**：16张 × 1.5倍（含返工） ≈ $24
- **高级模式**：20张 × 1.5倍 ≈ $30
- **自定义场景模式**：
  - 基础棚拍：16张 × 1.5倍 ≈ $24
  - 每个场景：8张 × 1.3倍 ≈ $10-11
  - 示例（2个场景各8张）：$24 + $10 + $10 ≈ $44

可在配置中设置 `budget_cap_usd` 限制最大花费。

## 自定义场景模式详细说明

### 工作流程
1. **阶段1**：生成16张高质量白背景棚拍图（与标准模式相同）
2. **阶段2**：从16张中选择合适的图片（均匀分布或用户指定）
3. **阶段3**：将选中的图片与用户提供的场景背景合成
4. **阶段4**：每张场景版本独立审核（A级进入 `final/{场景名}/`）

### 场景背景图最佳实践
✅ **推荐的场景类型**：
- 现代咖啡厅（窗光充足）
- 简洁城市街道
- 品牌零售空间
- 公园/花园（柔和自然光）
- 当代办公大堂

❌ **避免的场景类型**：
- 夜店/酒吧（光照复杂）
- 人群密集的市场
- 极端广角建筑照片
- 背景中有人物的照片
- 景深过浅的背景

### 常见问题

**Q：场景版本看起来像抠图，不自然怎么办？**
- 检查场景光照方向是否与模特匹配
- 确保场景色温不要太极端
- 在配置中详细描述阴影方向和地面材质

**Q：能同时使用几个场景？**
- 建议2-3个场景，成本可控
- 每个场景建议6-8张图片

**Q：可以使用品牌自己的店铺照片吗？**
- 可以！这是自定义场景模式的主要用途之一
- 确保照片符合技术要求（分辨率、清晰度、前景空间）

**Q：生成过程中我需要做什么？**
- 通常无需介入，系统全自动运行
- 只有在素材不足或超出预算上限时才会请求确认
- 生成完成后查看 `final/` 目录中的成品图
- 如有未通过的图片，在 `human-review/` 中人工检查

**Q：如果有图片未通过审核怎么办？**
- 系统会自动重试3次（标准模式）或5次（高级模式）
- 3/5次后仍未通过，图片会放入 `human-review/` 目录
- 查看该目录下的图片和审核意见，决定是否手动调整或重新生成

**Q：能修改已生成的图片吗？**
- 系统不会修改源图片或已生成的成品图
- 如需调整，创建新的任务版本（如 `job_v2_20260819/`）

## 完整流程详解

详细的工作流程文档请参考 `references/workflow-stages.md`（英文）。以下是简化版说明：

### 阶段一：准备（自动）

1. **检查素材**：系统自动检查模特照片、商品图、造型图是否齐全
2. **提取特征**：自动分析每张参考图，提取详细的人物、服装、造型特征描述
3. **生成计划**：根据选择的模式（标准/高级/自定义场景）规划生成方案
4. **估算成本**：显示预估费用，如果超出预算上限会请求确认

### 阶段二：生成（自动）

**标准/高级模式**：
- 逐张生成16张（或配置数量）图片
- 每张生成后自动审核（A/B/C评级）
- B/C级图片自动重试（最多3次或5次）
- A级图片自动进入 `final/` 目录

**自定义场景模式**：
- 先生成16张标准棚拍图
- 然后为每个场景生成对应版本
- 保持人物、服装、姿势完全一致
- 只替换背景和光照环境

### 阶段三：交付（自动）

系统自动生成：
- 所有A级图片（目标16张或更多）
- 完整的任务记录（JSON格式）
- 成本统计报告
- 如果有未通过的图片，放入 `human-review/` 供人工检查

## 边界

Agent 不会自动发布到淘宝、独立站或社交平台，不会修改源图片，也不会覆盖已有成品任务。

完整流程依赖 `$taobao-lookbook-reviewer`，建议同时安装。

完整的技术文档和工作流程详见 `references/workflow-stages.md`（英文）。
