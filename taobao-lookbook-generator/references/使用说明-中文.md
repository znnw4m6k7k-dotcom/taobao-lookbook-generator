# 淘宝 Lookbook 生图 Agent 中文说明书

## 它能做什么

根据用户提供的成年模特、商品正反面与细节、完整穿搭参考，生成一套16张竖版淘宝服饰 Lookbook：12张高调极简棚拍和4张干净城市街拍。每张图独立生成并交给 `$taobao-lookbook-reviewer` 审核，只有 A 级图片进入最终目录。

## 使用前准备

- 一位已获得 AI 生成和商业使用授权的成年模特：清晰人脸和全身比例参考。
- 一个 SKU、一个颜色；不同颜色必须分开任务。
- 商品正面、背面和关键细节图。
- 完整穿搭正面、背面参考，包括需要保留的鞋与配饰。
- 指明商品类型：连衣裙、上装、下装、套装或外套。

如果关键视图缺失、模糊、被遮挡或互相矛盾，Agent 会停止并要求补图，不会猜测商品结构。

## 在 Codex 中怎么说

上传或给出素材文件夹后发送：

```text
使用 $taobao-lookbook-generator，根据这个素材文件夹生成16张3:4淘宝 Lookbook。先检查模特授权、商品正反面、细节和完整穿搭是否齐全；逐张生成，并用 $taobao-lookbook-reviewer 审核。
```

## 固定输出

- 16张独立 JPG，1536 × 2048，3:4。
- 12张纯白至浅冷灰高调极简棚拍。
- 4张干净现代城市街拍。
- 同一模特、同一商品、同一颜色和同一完整搭配。
- 无文字、水印、拼图、第三方 Logo 或虚构品牌。

12个人物镜头会从内置的12张动作卡中抽卡式生成，按正面、侧面、背面、行走和三分之四机位匹配，并在同组内尽量不重复；4张商品细节图不参与动作抽卡。没有真实口袋、肩带或配饰时，不会为了完成动作而凭空添加。

棚拍默认使用左前方30–45度超柔和大面积光源、70–85mm中长焦透视、f/5.6–f/8、略亮但高光不溢出的曝光、低对比中性色调、自然皮肤与织物纹理。

## 审核与返工

- A：可以进入 `final/`。
- B/C：根据审图 Agent 的具体意见只返工当前镜头。
- 每张最多自动返工两次。
- 第二次返工后仍不合格，进入 `human-review/`，不能冒充完成。

## 边界

Agent 不会自动发布到淘宝、独立站或社交平台，不会修改源图片，也不会覆盖已有成品任务。

完整流程依赖 `$taobao-lookbook-reviewer`，建议同时安装。
